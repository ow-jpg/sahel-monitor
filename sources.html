Sources and filters Everything the collector looks at, and every rule it applies.

Checking

This page is written by the collector on every run, so it is always what the system is actually doing rather than what it was once set up to do. All of it comes from one file, sources.yml, in the repository.

An item has to mention a listed place to appear anywhere on the site. It then picks up themes and event types on top of that. If something you expect to see is missing, the cause is usually a place name or a term that is not in these lists, rather than a missing feed.

Feeds

Marked direct where the outlet publishes its own feed, and search where it is reached through a Google News query instead, which is how publications without a usable feed of their own get covered. Counts are from the most recent run.

Academic searches

Run against OpenAlex, which indexes journals and working papers. Free and needs no account.

Places

An item must match at least one of these to be kept at all. Matching ignores accents and only fires on whole words, so Mali is not matched inside Somalia. Tier 1 is the focus, tier 2 is tracked.

Themes

Colour coded across the site and used as the filter buttons. An item can carry several, or none.

Event types

Applied on top of themes, and shown as a badge on each item.

Discounted and excluded

Corroboration counts are meant to show how many independent newsrooms carried a story. Wire copy is counted once no matter how many outlets run it, and republishing platforms are ignored entirely, otherwise one agency report would look like six confirmations.

Adding or removing a source

Edit sources.yml in the repository and commit. That triggers a fresh run on its own. To add a publication with no feed of its own, copy an existing search entry and change the site in the query.

Scratchpad

Somewhere to note sources to add as you think of them. Saved in this browser only, so it will not survive clearing your browsing data and will not appear on another machine. Copy it out once you have a list worth keeping.

Every feed listed here is polled on the same schedule. A source appearing in this list is not a judgement about its reliability, and several of them are state owned or carry declared positions. The site does not label them as such, so that assessment is yours.
